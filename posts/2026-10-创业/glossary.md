创业必知术语清单

## 一、做产品：先验证有没有人需要

| 术语                              | 中文含义             | 记住这一点就够了                                   |
| --------------------------------- | -------------------- | -------------------------------------------------- |
| **MVP**（Minimum Viable Product） | 最小可行产品         | 用尽量简单、但可供真实用户使用的产品验证需求。     |
| **POC**（Proof of Concept）       | 概念验证             | 先证明一个想法或技术“做得出来”；不等于用户愿意买。 |
| **PMF**（Product-Market Fit）     | 产品与市场契合       | 产品满足了真实需求，用户愿意持续使用或付费。       |
| **Pivot**                         | 转向、转型           | 发现原方向行不通后，调整产品、客户或商业模式。     |
| **Traction**                      | 业务进展、市场牵引力 | 能拿出用户、收入、留存等实际成果，而不只是讲设想。 |
| **ICP**（Ideal Customer Profile） | 理想客户画像         | 最有可能需要、购买并持续使用你产品的是哪类客户。   |

**最容易混淆：POC 证明“能做”，MVP 用来验证“有没有人用”，PMF 说明“市场持续需要”。**

## 二、讲清市场：你做什么，卖给谁

| 术语                    | 中文含义                             | 记住这一点就够了                                       |
| ----------------------- | ------------------------------------ | ------------------------------------------------------ |
| **Pitch**               | 项目推介                             | 用简洁的话讲清问题、方案、市场和进展。                 |
| **Pitch Deck / BP**     | 融资演示文稿／商业计划书             | 给投资人看的项目材料；口语中有人把融资 PPT 也叫“BP”。  |
| **TAM / SAM / SOM**     | 总体潜在市场／可服务市场／可获得市场 | 分别回答“市场有多大”“我能服务多少”“我现实能拿到多少”。 |
| **GTM**（Go-to-Market） | 市场进入策略                         | 第一批客户从哪里来，怎么卖出去。                       |
| **Moat**                | 护城河                               | 当别人模仿你时，你有什么持续优势。                     |

## 三、谈融资：钱从哪来，股权怎么变

| 术语                                           | 中文含义             | 记住这一点就够了                                             |
| ---------------------------------------------- | -------------------- | ------------------------------------------------------------ |
| **VC**（Venture Capital）                      | 风险投资／风投机构   | 投资高增长潜力公司的资金或机构。                             |
| **CVC**（Corporate Venture Capital）           | 企业风险投资         | 大公司开展的风险投资，可能同时看财务回报和战略协同。         |
| **Seed / Series A、B…**                        | 种子轮／A 轮、B 轮等 | 融资轮次名称；不同公司的实际规模和阶段不一定相同。           |
| **Term Sheet（TS）**                           | 投资条款清单         | 投资人提出的主要交易条件，正式签约前要重点看。               |
| **DD**（Due Diligence）                        | 尽职调查             | 投资人核查公司业务、财务、法律等情况。                       |
| **Pre-money / Post-money Valuation**           | 投前／投后估值       | 简单股权融资中，投后估值≈投前估值＋本轮新投资额。            |
| **Cap Table**                                  | 股权结构表           | 谁持有公司多少股份，以及相关权益安排。                       |
| **Dilution**                                   | 股权稀释             | 公司发行新股后，原股东的持股**比例**可能下降。               |
| **SAFE**（Simple Agreement for Future Equity） | 未来股权简单协议     | 投资人先出资，未来符合约定条件时取得股份；签署时通常尚未持股。 |
| **Liquidation Preference**                     | 清算优先权           | 在约定的出售、清算等情形下，投资人优先参与分配的权利；具体能拿多少要看条款。 |

## 四、看数据：增长了，还是只是看起来热闹

| 术语                                 | 中文含义             | 记住这一点就够了                                             |
| ------------------------------------ | -------------------- | ------------------------------------------------------------ |
| **SaaS**（Software as a Service）    | 软件即服务           | 持续向客户提供软件服务，常见订阅或按用量收费。               |
| **MRR / ARR**                        | 月度／年度经常性收入 | 衡量订阅业务规模；口径一致时，常用 **MRR × 12** 估算 ARR。   |
| **Revenue**                          | 收入                 | 公司按适用会计规则确认的收入；不等于收进来的全部现金。       |
| **GMV**                              | 交易总额             | 平台促成的交易规模；**不等于平台收入**。                     |
| **CAC**（Customer Acquisition Cost） | 获客成本             | 获得一位新客户花多少钱。                                     |
| **LTV / CLV**                        | 客户终身价值         | 一位客户在整个合作期间预计带来的价值；使用时要说明按收入还是毛利计算。 |
| **Gross Margin**                     | 毛利率               | 扣除直接成本后，还剩多少比例。                               |
| **Burn Rate**                        | 资金消耗速度         | 公司每月大约消耗多少现金。                                   |
| **Runway**                           | 现金跑道             | 按目前的现金消耗速度，账上的钱还能支撑多久。                 |
| **Retention / Churn**                | 留存／流失           | 客户是否继续使用或付费，以及有多少客户离开。                 |
| **NRR**（Net Revenue Retention）     | 净收入留存率         | 只看原有客户：计入增购、降级和流失，**不计新客户**。         |

## 五、带团队：把事情稳定地做出来

| 术语                                    | 中文含义       | 记住这一点就够了                           |
| --------------------------------------- | -------------- | ------------------------------------------ |
| **SOP**（Standard Operating Procedure） | 标准操作程序   | 把重复性工作的方法、责任和标准写清楚。     |
| **KPI**（Key Performance Indicator）    | 关键绩效指标   | 用于持续衡量业务或岗位表现的指标。         |
| **OKR**（Objectives and Key Results）   | 目标与关键结果 | 写清楚“要实现什么”，以及“怎样判断实现了”。 |

**如果还想再缩成一页纸，最先熟悉这 15 个：Pitch、MVP、PMF、ICP、TAM、GTM、Traction、VC、CVC、Term Sheet、Valuation、Dilution、ARR、CAC、Runway。**其余遇到时再查，不用一次背完。
